# Sanpo Quest 画像素材 仕様書(GPT などの画像生成用)

目的: アプリのデザインを一新するための「部品」を、画像生成(ChatGPT の画像生成など)で作るときの決めごと。
**いちばん大事なのは「統一感」**です。1つ1つがきれいでも、タッチがばらばらだと素人っぽく見えます。

## 0. 進め方(初心者向け)
1. 最初に「スタイル見本」を1枚だけ、納得いくまで作る(下の「共通プロンプト」を使う)。
2. 以降は、**そのスタイル見本の画像を毎回添付して**、「この絵と同じタッチで」と頼む(同じチャットの中で続けると、ぶれにくい)。
3. 1つの部品につき、4案ずつ作らせて、いちばん良いものを選ぶ。
4. 選んだ画像を、**このチャットに添付して送る**(1回に6枚くらいまで)。ファイル名の代わりに、「これは◯◯」と書いて教えてください。
5. 私(Claude)が、背景を透明にして、余白を切り、各サイズ(1024 / 256 / 128 / 64px)に変換して、アプリに組み込みます。

## 1. スタイルの決めごと(全部品に共通)
- 世界観: **絵本のジオラマ**。やわらかいパステル、あたたかい雰囲気、丸みのあるかわいい形。
- 線: **こげ茶色(#4a3424)の、太めで均一な輪郭線**。線の太さは、絵の高さの約3%。すべての部品で同じにする。
- 塗り: ベタ塗り + やわらかい2段階の影(セル塗り風)。ハイライトは、左上から。グラデーションは、ほんの少しだけ。
- 角度: キャラクターは「正面より少し斜め上から見た立ち姿(3/4ビュー)」。建物・名所も、同じく斜め上から。**角度は全部品でそろえる**。
- 禁止: 文字・ロゴ・透かし・背景の景色・実在のキャラクターや作品に似せること・写実的な質感・暗くて怖い表現。
- 影: 地面の影は、描かない(アプリ側でつけます)。

## 2. 技術の決めごと
- 形式: **PNG(透明な背景)**。1024 × 1024px の正方形。
- 絵は、中央に、全体の約80%の大きさで(まわりに余白を残す)。
- 透明にできないときは、「背景は、**ベタ塗りの黄緑(#00FF00)だけ**」にしてください。私が、切り抜きます。
- 白や、グラデーションの背景は、切り抜きにくいので、避ける。
- 1つの画像に、1つの部品だけ(並べたシートではなく、1枚1つ)。

## 3. 共通プロンプト(コピーして使う)
英語のほうが、安定しやすいです。

```
Cute storybook diorama game asset, soft pastel colors, warm and friendly mood,
thick even dark-brown outline (#4a3424), flat colors with gentle two-step cel shading,
highlights from the upper left, rounded cute proportions, slightly top-down 3/4 view,
single object centered, fills about 80% of a square 1024x1024 canvas,
transparent background (or plain flat #00FF00 background if transparency is not possible),
no text, no logo, no watermark, no ground shadow, no scenery, not photorealistic.
Subject: 【ここに、お題を書く】
```

### お題の書き方の例
- キャラクター: `Subject: a cute little fox child adventurer in a green cape, standing, full body, front 3/4 view, holding a small lantern`
- 名所: `Subject: a small mossy stone shrine with a red torii gate, 3/4 view`
- アイコン: `Subject: a golden coin with a star emblem (icon style, simple, bold shapes)`

### F. ロゴ・アプリアイコン・起動画面
- ロゴ: 「散歩クエスト / Sanpo Quest」(文字は、あとで私が重ねるので、絵だけでもOK)
- アプリアイコン: 512 × 512px、背景つき(ふちが丸く切られても大丈夫なよう、中央に)

## 5. 確認リスト(送る前に)
- [ ] 全部の部品で、輪郭線の色と太さが、同じに見える
- [ ] 角度(斜め上から)が、そろっている
- [ ] 文字・ロゴ・透かし・景色が、入っていない
- [ ] 背景が、透明(または、ベタ塗りの黄緑)
- [ ] 全体の80%くらいの大きさで、中央にある
- [ ] 実在のキャラクターに似ていない

## 6. 権利について
- ChatGPT などで作った画像を、アプリに使えるかは、そのサービスの利用規約によります。個人・家族で使う分には、通常問題ありませんが、公開・販売をするときは、規約を確認してください。
- 実在の作品やキャラクターを連想させる指示(「◯◯風」など作品名)は、避けてください。
