# Sanpo Quest イラスト指示書(全部まとめ)

ChatGPT に貼る指示を、素材ごとにまとめました。**同じチャットで、見本(けんし)を添付したまま**進めると、絵のタッチがそろいます。
できた絵は、**このチャットに添付して送り、「これは◯◯」と名前を書いてください**。背景の透明化・余白・サイズ変換・組み込みは、Claude がやります。

## 0. 毎回の頭につける共通文(最初の1回、または毎回)
```
同じタッチ(今まで作ったキャラ・コイン・宝箱と同じ線の太さ・色合い・角度)で作ってください。
背景は透明。1枚に1つだけ。絵は中央に、全体の約80%の大きさで。文字・ロゴ・透かし・背景の景色・地面の影は入れない。
```

## 2. メニューのアイコン(いちばん効果が大きい。次にやる)

## 6. ステッカー・イベント限定(新しいイベントのとき)
丸いシール風。白いふちどり。中に1つの絵。
```
【お題】(イベント名)のステッカー。丸いシール。白いふちどり。真ん中に、イベントの象徴の絵
```

イベント限定キャラは、**元のキャラ(けんし等)とは別の動物・種族**にすると、特別感が出ます。例:
- ふうせんくま: 風船を持つ、くま
- にじいろうさぎ: 虹色の耳のうさぎ
- ほしのりゅう: 星をつけた小さな龍の子

## 7. ロゴ・アプリアイコン
**ロゴ** — `logo`
```
【お題】「散歩クエスト」のロゴの絵だけ(文字は入れない)。小さな冒険者と、地図のピンと、足あと。丸い組み合わせ
```

**アプリアイコン** — `app-icon`(正方形・背景つき・縁が丸く切られても大丈夫なよう中央に)
```
【お題】正方形のアプリアイコン。背景は、夜空の紫から金色のグラデーション。真ん中に、けんしのキャラ。角は丸くしない(私が丸めます)
```

## 8. うまくいかないとき
- 線の太さや色が毎回ちがう → 見本を再添付して、「この絵と、線の太さ・色を完全にそろえて」と頼む
- 背景が透明にならない → 「背景は、ベタ塗りの黄緑 #00FF00 だけに」
- 文字や影が入ってしまう → 「文字・ロゴ・地面の影は、描かないで」
- 3段階がバラバラ → 「段階1の絵を添付して、同じ物が育ったように、段階2を作って」
- 作品名は出さないでください(「◯◯風」などは避ける)

## 9. 送り方
- 1回に6枚くらいまで。名前を書いて送ってください(例: 「icon-foot」「poi-古城」「item-castle-2」)。
- 送る前のチェック: 線の太さがそろっている / 角度がそろっている / 文字・影が入っていない / 背景が透明 / 実在のキャラに似ていない
