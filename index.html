🗺️ 冒険モード

歩いた距離は 👣 として貯まります(10mで1)。冒険モードでは、現実の場所に関係なく、地図をタップした場所へ👣を使って歩いて行けます(10mで1)。霧・コイン・名所は進みますが、「歩いた距離」には数えません。

📥 GPSログの取り込み

GPX / TCX / KML / GeoJSON / CSV / Googleの位置履歴(JSON・Takeout の ZIP)に対応。形式が分からないJSONでも、座標らしい値を探して読み取ります。歩いた道の霧が晴れ、通った県・市区町村、道すじ沿いの名所も記録され、距離が👣になります。速度の制限はなく、電車や車の移動も、記録のとおりに反映されます。

💡 ホーム画面に「インストール」しておくと、GPSLoggerなどのアプリで、GPXを「共有」→「Sanpo Quest」を選ぶだけで取り込めます。
