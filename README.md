# Sanpo Quest（散歩クエスト）

現実の街を歩いて冒険する散歩アプリ（ビルド不要、静的ファイルのみ）。

- 現実の地図を古地図風に表示。歩いた場所の霧が晴れ、歩いた道は光る線で残る
- 現実の神社・公園・駅・史跡・カフェなどが、❓の名所として地図に現れる。近づくと発見（ほこら／森の広場／旅の門／古い遺跡／旅人の宿 …）
- 名所の読み込みは、4つのOverpassサーバーへ時間差で同時に問い合わせて最速の答えを使い、一度取得した名所は端末に保存(次回からは即表示)。読み込めないときは画面に表示して自動でやり直す
- 🌀 ワープゲート: 行ったことのある場所(霧が晴れた所)に30🪙で置ける(最大12個)。冒険モード(🗺️)では、ゲートの一覧や地図のゲートから、どこへでも一瞬でワープできる
- ⚙️ 冒険モードのパネルで、👣を自由に付与(加算)・設定できる
- 市区町村の記録ができる前に取得した名所も、起動後に自動で県・市区町村ごとに振り分け(失敗しても20秒ごとに再試行。冒険の書に進み具合を表示)
- ⚡ かるいモード(🗺️パネル): 飾り・アニメ・3D建物をやめて軽くする。最初の6秒で動作が重いと自動で有効に。霧は見えている範囲だけ描画、名所の印は遠くなったら外す
- 次の❓までの距離と方角を表示
- 歩くと地図に🪙💰💎が現れ、近づくと拾える。名所の発見やレベルアップでもコインがもらえる
- 🔨 でコインを使って、花畑・木・休憩所・ちょうちん・池・ほこら・おうち・塔・おしろを自分の40m以内に置ける。置いた物は場所に結びついて保存される
- 置いた物はコインを生産し(最大8時間分)、近くに行くと収穫できる。ちょうちん/塔はコインを呼び、ほこらは拾うコインを2倍にすることがある
- 🔮進化のかけら(地図で拾う／名所発見・レベルアップで入手／60🪙で購入)とコインで、遠くからでも進化できる(例: 🏠→🏡→🏘️)。取り壊すと投資額の半分が戻る
- 歩くだけでも、通った都道府県・市区町村を自動で記録(500mごとに確認)
- 📖 冒険の書の「日本地図」で、本物の形の都道府県が、訪れるたびに金色に塗られていく。「称号」で達成状況を確認(名所ハンター・県めぐり・町めぐり・地方制覇…)。達成で報酬、最初の地方制覇などで特別な物(🗿記念碑・🌈虹のアーチ)が解放
- 発見した名所は 📖 冒険の書 に、都道府県 → 市区町村 → 町ごとに記録(タップするとその場所へ移動)。初めての県・市町村にはボーナス。住所は OpenStreetMap の Nominatim で取得
- データは端末の localStorage に保存。地図は OpenFreeMap(OpenStreetMap のデータ)、名所データは OpenStreetMap(Overpass API) から取得
- PCで試すときは 🧪 をONにして地図をクリックすると現在地がワープ

## 起動
```
python3 -m http.server 8000
```
スマホ実機では Geolocation に HTTPS が必要（GitHub Pages で公開すると確認しやすい）。

## 市区町村の達成度・天気・称号
- 歩いた市区町村ごとに、その町の名所の総数を OpenStreetMap(Overpass API) で調べ、発見した割合(25/50/75/100%)に応じて報酬(★・制覇)
- 天気は Open-Meteo から取得(歩いた距離を雨の日・雪の日・暑い日・寒い日で数え、称号に使う。画面に雨・雪も降る。`?weather=rain` で確認可)
- 称号は早朝・夜・雨雪・気温・1日の距離・連続さんぽ・累計距離など

## クレジット
- 地図データ: © OpenStreetMap contributors / OpenFreeMap / OpenMapTiles
- 日本地図の形: 国土地理院「地球地図日本」(2016) を、jpn-atlas(BSD-3-Clause) 経由で簡略化して使用(`jpmap.js`)

## 冒険モードとGPSログの取り込み
- 歩いた距離は 👣(10mで1)として貯まる。🗺️ から冒険モードにすると、現実の場所に関係なく、地図をタップした場所へ👣を使って歩ける(10mで1)。霧・コイン・名所・地域の記録は進むが、「歩いた距離」には数えない。GPSが取れないときは自動で冒険モードで始まる
- あとからGPSログを取り込める(GPX / TCX / KML / GeoJSON / CSV / Googleの位置履歴JSON)。記録のとおりに(速度の制限なし。電車・車の移動も含む)、霧・足あと・距離(👣)・通った県と市区町村・道すじ沿い50m以内の名所を反映。道すじ1本ずつ取り込み済みかを判定し、重なった期間を入れ直しても二重に取り込まない。期間(直近1週間〜すべて)を選んで取り込める。Googleマップのタイムライン(新旧の書き出し形式・TakeoutのZIP)も読み、形式が分からないJSONでも座標らしい値を探して読み取る(読めなかったときは構造の診断を表示)。このアプリの足あとをGPXで書き出すこともできる

## アプリとして使う・共有から取り込む・記録
- ホーム画面に「インストール」(PWA)すると、GPSLoggerなどのアプリで、GPXを「共有」→「Sanpo Quest」を選ぶだけで取り込める(`manifest.webmanifest` の share_target と `sw.js`)
- 🗺️の「画面をつけたままにする」で、ゲーム中に画面が消えにくくなる(Screen Wake Lock)
- 現実のGPSを、時刻つきで記録し(速度の制限なし)、時刻つきのGPXとして書き出せる。画面を消している間の記録は、ブラウザの制限で保証できないため、長い散歩はGPSLoggerなどのロガーを併用するのがおすすめ

## 読み込めないとき(GPSログの取り込み)
- ファイル選択に種類の指定は付けていない(Androidで、GPXが灰色で選べなくなるのを避けるため)。選べない場合は、🗺️の「中身を貼り付けて取り込む」を使う
- 取り込む期間の初期値は「すべて」。期間を絞って記録がなかった場合は、理由を表示して「すべて」に戻す
- GPX・CSV・テキストの書式が崩れていても、座標らしい値を直接探して読み取る。読めないときは、ファイルの構造の診断を表示する

## GPSのゆれ
- 止まっていてもGPSは数mゆれるため、現実で歩いた距離には、GPSの誤差(精度)より大きく動いたときだけを数える
- 取り込みでも、前の点から8m未満の動きは「ゆれ」として無視する。短い記録(ほとんど動いていない記録)も取り込める
- このアプリ自身が書き出したGPXを取り込んだときは、距離と👣を二重に足さない(霧・地域・名所だけ反映)

## 名所のグラフィック
- 名所は15種類(神社・お寺・教会・お城・遺跡・公園・庭園・展望台・石像・水晶・博物館・駅・温泉・カフェ・図書館)。OpenStreetMapのタグから種類を判定し(`classify`)、それぞれ専用の絵(`art.js` の `POI`)で表示
- 陰影とツヤのある絵で、炎のゆらぎ・水晶の脈動・湯気・星のまたたき・門の渦などが動く
- 未発見は光る謎の宝珠(周りを光の粒が回る)。発見後は種類ごとの色に光る石の台座と、巻物風の名札

## 冒険モードから現実の現在地へ戻る
- 冒険中は、画面下に「現実のあなたは○km△の方角」のバーと「現実の現在地へ戻る」ボタンを常に表示。現実の位置には「現実のあなた」の分身も立つ(タップでも戻れる)
- 戻るときは、分かっている現実の位置にキャラとカメラを一瞬で合わせ、そのあと最新のGPSに取り直す。冒険を始めたら、カメラは移動するキャラを追いかける
- GPSが遅れて、自動で冒険モードで始まった場合は、位置が取れた時点で現実モードに切り替わる

## ボリューム(レベル・つくる物・デイリー)
- レベルは30段階(その先も「散歩の神話 +1, +2…」と続く)。経験値は、歩いた距離(m)＋名所×300＋行動(新しい町100・新しい県500・称号150・つくる/進化はコストの半分・コイン拾いなど)。レベルアップごとに報酬(🪙と🔮)
- つくれる物は16種類。畑(Lv3)・牧場(Lv5)・風車(Lv7)・灯台(Lv10)・遊園地(Lv14)を追加(各3段階に進化)
- 称号は50個。デイリーミッションは毎日3つ(歩く・名所・ほかの行動)＋全達成ボーナス。画面上の「📋2/3」をタップで確認
