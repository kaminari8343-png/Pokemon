# Sanpo World（散歩ワールド）

現実で歩くと、ブラウザの中の別世界を歩ける散歩アプリ（ビルド不要、静的ファイルのみ・外部ライブラリなし）。

- 緯度経度から海・森・山・砂浜などのファンタジー世界を自動生成（同じ場所は常に同じ地形）
- 歩いた周囲約70mの霧が晴れ、名所（城あと・泉・ほこら…）を発見できる
- 現実の時刻に合わせて夜は暗くなる
- 今日の散歩距離・ひらいた土地・みつけた名所を表示。データは端末の localStorage に保存
- PCで試すときは 🧪 をONにして画面をタップすると現在地がワープ

## 起動
```
python3 -m http.server 8000
```
スマホ実機では Geolocation に HTTPS が必要（GitHub Pages で公開すると確認しやすい）。
