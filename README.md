# Walk Monsters

位置情報を使って、歩いてモンスターを集めるゲームのプロトタイプ（ビルド不要、静的ファイルのみ）。

## 遊び方
- 現在地の周囲にモンスターが出現。40m以内まで歩いて近づき、タップで捕獲画面へ。
- 緑ゾーンでボタンを押すと成功率アップ。図鑑と歩行距離は localStorage に保存。
- PCで試す場合は「テスト移動」をONにして地図をクリックすると現在地がワープ。

## 起動
```
python3 -m http.server 8000
```
スマホ実機で試す場合、Geolocation は HTTPS（または localhost）が必須。GitHub Pages などで公開すると確認しやすい。

## 構成
- `game.js` … 位置追跡・出現・捕獲・図鑑のロジック
- `SPECIES` を編集するとモンスターを追加可能
